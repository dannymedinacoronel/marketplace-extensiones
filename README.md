# Marketplace de extensiones

Catálogo interactivo de las extensiones públicas de Danny Medina Coronel, con capturas, novedades, instalación y enlaces a GitHub y Chrome Web Store.

## Sitio web

https://dannymedinacoronel.github.io/marketplace-extensiones/

## Desarrollo local

Abre `index.html` en un navegador. El catálogo incluye una colección local para estar disponible aunque GitHub limite las consultas. Usa el botón «Actualizar» para consultar los repositorios y las últimas versiones en GitHub.

## Publicación

El sitio se publica desde la rama `main`, en la raíz del repositorio, mediante GitHub Pages.
